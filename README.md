# ¿Qué Cambió?

## Frase de la ficha
Encontrá las diferencias entre dos cuadrículas casi idénticas antes de que se agote el tiempo.

## Descripción
Observá las matrices A y B y seleccioná en la segunda las celdas que cambiaron.  
Usá el teclado o la pantalla táctil para jugar.  
Encontrá todas las diferencias antes de que termine el tiempo.


## Ejecución local
1. Cloná el repositorio: `git clone <https://github.com/DanielaYamileth6376115/proyecto15_que_cambio_6376115.git>`
2. Entra a la carpeta: `cd proyecto15`
3. Instala las dependencias: `npm install`
4. Inicia el servidor: `npm run dev`
5. Ejecuta las pruebas: `npx vitest run`
6. Compila el proyecto: `npm run build`
